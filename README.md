# HardwareExpert

**HardwareExpert** — это мобильное приложение, представляющее собой экспертную систему на базе продукций для диагностики аппаратных неисправностей персональных компьютеров и ноутбуков. 

Приложение работает **полностью офлайн**, не требует интернет-соединения, обеспечивает мгновенный отклик и абсолютную конфиденциальность пользовательских данных.

## Ключевые возможности

- **Два режима диагностики**: разделение базы знаний на настольные ПК (PC) и ноутбуки (Laptop).
- **Поддержка брендов**: для ноутбуков реализован выбор бренда (ASUS, Lenovo, Dell, HP, Apple, MSI, Acer, Huawei, Xiaomi, Surface) для поиска специфичных поломок.
- **Умный поиск (NLP)**: встроенный алгоритм распознает естественный язык. Введите: *«почему у меня блютуз отваливается»*, и система уберет стоп-слова, заменит синонимы на официальные термины и найдет нужный симптом *«Bluetooth отключается»*.
- **129 развернутых правил**: база содержит подробные причины неисправностей и пошаговые инструкции (от 3 до 4 шагов) по их устранению.
- **Множественный вывод**: при выборе нескольких симптомов система выводит список *всех* подходящих причин в виде карточек, а не только одну.
- **Интерактивная история**: все запросы сохраняются в локальной БД (Room). Любую сохраненную запись можно открыть повторно, чтобы освежить в памяти рекомендации.
- **Стильный дизайн**: тёмная тема Navy Blue, моноширинный шрифт, glow-эффекты на кнопках и кастомная иконка микрочипа с кардиограммой.

## Стек технологий и архитектура

Проект построен по классической трехуровневой архитектуре:
1. **UI (Presentation)**: Декларативный интерфейс на **Jetpack Compose** (Material 3). Экраны: `DeviceSelectionScreen`, `HomeScreen`, `ResultScreen`, `HistoryScreen`.
2. **Domain (Logic)**: Ядро системы. Класс `ExpertSystem` (прямой вывод) и `SearchHelper` (обработка естественного языка).
3. **Data**: Локальная база данных **Room (SQLite)** для истории и JSON-база правил в `assets/rules.json`.

| Технология | Назначение |
|---|---|
| **Kotlin** | Основной язык программирования |
| **Jetpack Compose** | Создание пользовательского интерфейса |
| **Room** | Локальное хранение истории запросов |
| **Gson** | Парсинг базы знаний `rules.json` |
| **Coroutines** | Асинхронная работа (имитация загрузки поиска, работа с БД) |

### Как работает алгоритм поиска (NLP)
1. Текст пользователя очищается от знаков препинания и переводится в нижний регистр.
2. Удаляются «стоп-слова» (предлоги, вводные слова: *почему, на, компе, всё время*).
3. Словарь синонимов заменяет жаргонизмы на официальные термины (*винт -> жёсткий диск, вайфай -> wifi, видюха -> видеокарта*).
4. Оставшиеся ключевые слова сравниваются с симптомами в базе, при этом алгоритм игнорирует дефисы и пробелы.
