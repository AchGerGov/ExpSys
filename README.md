# HardwareExpert

Мобильная экспертная система на базе продукций для диагностики аппаратных неисправностей ПК и ноутбуков.

## Возможности

- **187 продукционных правил** в базе знаний: питание, перегрев, ОЗУ, HDD/SSD, GPU, материнская плата, экран, клавиатура, тачпад, USB, звук, сеть, Bluetooth, батарея ноутбука, BIOS/UEFI, POST-сигналы и бренд-специфичные проблемы (ASUS, Dell, HP, Lenovo, MSI, Apple, Surface, Samsung, Huawei, Xiaomi).
- **Поисковая строка** для быстрой фильтрации симптомов.
- **Прямой вывод (forward chaining)** — от симптомов к причине и рекомендациям.
- **История запросов** на Room (SQLite).
- **Полностью офлайн** — не требует интернета и внешних API.
- Тёмная тема **navy blue**, glow-эффект на кнопках, шрифт Consolas.

## Архитектура

```
UI (Compose)  →  ExpertSystem (логика)  →  rules.json + Room
```

- `logic/ExpertSystem.kt` — загрузка правил, прямой вывод, ранжирование по совпадениям.
- `data/*` — модель правила (`Rule`), Room-сущности для истории запросов.
- `ui/*` — три экрана: Home (ввод симптомов), Result (ответ), History (история).
- `assets/rules.json` — база знаний в формате продукций.

### Формат правила

```json
{
  "symptoms": ["Не включается", "Индикатор питания не горит"],
  "cause": "Неисправность блока питания или кабеля питания",
  "advice": "1) Проверьте кабель…\n2) Попробуйте другой кабель…"
}
```

### Машина вывода

1. Ищем все правила, где совпал хотя бы один симптом.
2. Ранжируем: сначала по числу совпадений, затем по «компактности» правила.
3. Если совпали **все** симптомы правила → ответ «База знаний».
4. Если только часть → ответ «База знаний (частично)» с предупреждением.
5. Если ничего не подошло → «Причина не определена» + рекомендация уточнить симптомы.

## Сборка

1. Установить **JDK 17** (Adoptium Temurin), **Android SDK** (API 34).
2. Клонировать репозиторий:
   ```bash
   git clone https://github.com/ваш-логин/HardwareExpert.git
   cd HardwareExpert
   ```
3. Создать `local.properties` со строкой:
   ```
   sdk.dir=/путь/к/Android/Sdk
   ```
4. Собрать APK:
   ```bash
   ./gradlew assembleDebug
   ```
   - Windows: `.\gradlew.bat assembleDebug`
5. Установить на телефон:
   ```bash
   adb install -r app/build/outputs/apk/debug/app-debug.apk
   ```

## Безопасность

- Приложение **не использует интернет** и не имеет разрешения `INTERNET`.
- Никакие данные пользователя не передаются третьим лицам.
- API-ключи и внешние сервисы **не используются** — вся логика локальная.
- Отказ от LLM обоснован требованиями дисциплины «Анализ безопасности систем ИИ»: детерминированность вывода, объяснимость (видно сработавшее правило), отсутствие утечек данных.
